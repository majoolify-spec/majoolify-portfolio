## Contexte du projet

Cette étude de cas explore un concept d’interface de jeu de stratégie centré sur la lisibilité dans des vues denses.

## Ce qui est en cours

- Une base UI modulaire pour les boucles de gameplay stratégie.
- Une hiérarchie visuelle pour la carte, les actions et les ressources.
- Des layouts responsive qui gardent les contrôles utilisables à chaque breakpoint.
